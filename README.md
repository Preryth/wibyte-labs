# WiByte Labs

WiByte Labs (WPL) is a browser-based programming laboratory providing students with isolated cloud development environments.

## Project Status

Early development — proof of concept.

## Local Linux deployment

Run `./wpl setup` for interactive Docker configuration, or `./wpl setup --check`
to validate an existing installation without changing it. See
[the setup guide](docs/setup.md) for requirements, private configuration,
adopting the existing local deployment, daily commands and provider callbacks.

## Planned Core

- Browser-based code editor
- File manager
- Interactive terminal
- Tkinter GUI streaming
- Isolated student containers
- GitHub integration
- Google Cloud infrastructure

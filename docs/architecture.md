# WPL Architecture

## Overview

WiByte Labs is a browser-based programming laboratory designed to provide students with isolated development environments.

## Core Components

- Frontend — Browser-based student interface
- Backend — API and session management
- Student Container — Isolated code execution environment
- Kubernetes — Container orchestration
- Google Cloud — Cloud infrastructure
- GitHub — Source control and student repository integration

## Development Strategy

The system will first be developed and tested locally using Docker.

Cloud deployment will be introduced after the local containerized system is working correctly.
